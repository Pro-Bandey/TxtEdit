# TxtEdit

**TxtEdit** is a powerful text and code editor available as a browser extension. Built on top of the widely used **CodeMirror** editor, it provides a fast, customizable, and feature-rich editing experience directly in your browser.

## Features

- 📝 Edit plain text and source code files
- 🎨 Highly customizable interface and editor settings
- 📂 Open, edit, and save files directly from your device
- ⌨️ Multiple editor keymaps, including popular layouts such as Sublime Text
- 🌐 Support for 100+ programming and markup languages, including:
  - JavaScript
  - TypeScript
  - HTML
  - CSS
  - JSON
  - Python
  - C/C++
  - Java
  - And many more
- 🧩 Available as a browser extension

## User Interface

When you launch TxtEdit, you'll find:

- **Left Sidebar**
  - Open files
  - Save files
  - Access settings and file management tools

- **Editor Area**
  - Powered by CodeMirror for efficient text and code editing

- **Right Sidebar**
  - Editor preferences
  - Appearance customization
  - Advanced configuration options

## File Access

### Modern Browsers

TxtEdit supports the **File System Access API**, allowing files to be opened, edited, and saved directly to your local filesystem without downloading copies.

### Legacy Browser Support

For browsers that do not support the File System Access API, TxtEdit automatically falls back to the browser downloads API for saving files.

## Privacy

- 🔒 No internet connection is required after the application loads
- 💻 All editing is performed locally in your browser
- 🚫 No external services are used for file processing
- 🔐 Your files remain on your device
